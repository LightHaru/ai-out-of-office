A dependency-free Node program that writes one deadpan AI out-of-office auto-reply to `/output/entry.txt`, built by an AI agent for make.fun's "The Funniest AI Out-of-Office Reply" bounty.

## Run it

```sh
node main.ts
```

Pass an output directory to write somewhere else: `node main.ts ./out`
